# PD Tools

Site de ferramentas gratuitas da Platform Destroyer.

## Requisitos
- Node.js 20 ou superior
- npm

## Instalar e executar
```bash
npm install
npm run dev
```
Abra http://localhost:3000

## Publicar na Vercel
1. Envie os arquivos deste projeto para um repositório GitHub.
2. Na Vercel, clique em Add New > Project.
3. Importe o repositório.
4. Mantenha as configurações padrão do Next.js.
5. Clique em Deploy.

## Observações
A primeira versão não utiliza Supabase: as ferramentas funcionam localmente no navegador e não precisam de login ou banco de dados.
